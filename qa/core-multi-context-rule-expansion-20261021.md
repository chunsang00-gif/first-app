# 실제 오행 상생 방향 수정 후 다섯 계절 관계를 반영한 첫 챕터 원고 검토

## 원인 분석
`report-seasonal-evidence.relation(hiddenElement, visibleElement)`의 `resource`는 숨은 글자의 오행이 겉글자를 생한다는 뜻인데, 기존 `report-chart-contrast.js`와 `report-core-knowledge-engine.js`의 이름/문장이 반대였다. 甲子(목 겉글자, 수 본기), 戊申(토 겉글자, 금 본기)를 독립 검증 예제로 고정하고 **해석 방향 매핑만 수정**했다. 계산 엔진은 그대로 유지했다.

## 후보 추가
기존 99건 QA 명식에서 우선 발견된 서로 다른 조합 네 건에 한정해 명리 검토용 독자 초안을 작성했다.

- 양력 1988-12-15 甲子: 비견 + 정인. 본기가 월의 겉글자 오행을 생함. 겨울 중심월·일간에 인성 계열. 역할과 배우는 기준의 관계를 가상의 모임 선택으로 풀이.
- 양력 1982-08-15 戊申: 편인 + 비견. 겉글자 오행이 본기를 생함. 가을 중심월·일간과 같은 오행. 새로운 해석 방식과 역할 구분이라는 가상 작업 장면.
- 양력 1994-09-15 癸酉: 정인 + 정관. 본기가 겉글자를 생함. 가을 중심월·일간을 극하는 계절. 알려진 설명을 이해하는 일과 규칙을 맡아 적용하는 일을 분리.
- 양력 2000-02-15 戊寅: 정관 + 상관. 본기의 오행이 겉글자를 극함. 봄 중심월·일간이 생하는 계절. 형식과 새 표현의 경계만 설명하고 심리적 갈등과 사건을 추정하지 않음.

4개 모두 `facts.build`가 실제로 해당 십성과 달의 본기를 계산한 경우에만 선택한다. 명식의 다른 위치·실제 행동·심리나 성과를 발명하지 않는다. 월별/계절별 분류가 달라도 같은 문장을 복사해 붙이지 않는다.

## 결과 범위
규칙은 2 → 6개. 고정 99건의 검토용 초안은 4 → 8건을 기대하며 나머지 91건은 기존대로 `not-covered`/reader null 상태를 유지한다. **사람의 전문 명리·문장 검수 미실시**이므로 유료 출시 품질 인증이 아니다. 유료 AI 호출 0회, 운영 브랜치와 기존 계산 엔진 수정 없음.
