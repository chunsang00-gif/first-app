# 사주 해석 DB v1.0 — 공통 관계 4종, 월별 독립 원고 9개

기존 12개 정확한 출생월 조합은 그대로 둔다. 반복 발견되는 네 가지 십성·오행 관계를 familyRules로 관리하되, 실제 독자용 후보는 반드시 각 출생월에 작성된 별도의 본문만 사용한다.

- 비견·정인 (亥, 午, 巳): 같은 분류의 생 관계라도 겨울 중심월과 여름 중심월은 다른 장면·해설을 사용.
- 편인·정재 (午, 巳): 익숙하지 않은 정보 이해와 반복 관리의 관계를 별개 월의 출처로 검증.
- 겁재·정인 (申, 酉): 공통 안내와 공동 사용 자원의 의미를 서로 다른 월지 자료로 구분.
- 비견·겁재 (子, 巳): 같은 오행이더라도 십성 세부 분류와 계절을 동일하다고 취급하지 않음.

각 family variant에는 고유의 제목, 요약, 장면, 별도 설명, 실제로 확인할 판단 문제, 주의 예시가 있다. 단지 원고에 단어만 교체해 재사용하는 방식을 금지한다.

편집 후보의 기준은 정확한 월지, 십성 쌍, 월지 본기, 오행 관계 방향, 계절 단계, 일간과 계절 오행 관계의 일치다. 계산상 불가능한 조합과 중복을 auditKnowledge에서 차단한다.

명리학 전문가 감수와 실제 유료 결과 평가를 거친 것은 아니다. 대상 연도, MBTI 또는 출생시각 변화로 월지 근거가 바뀌지 않는지도 별도 확인한다. 운영 앱, 원본 계산, 결제, 유료 API 실행 경로는 변경하지 않는다.

목표: 99건 고정 표본의 검토 원고 수 14 → 23, 미지원 85 → 76. 확정 수치는 CI 로그를 확인한다. 모두 유료 노출 미승인, API 비용 0.
