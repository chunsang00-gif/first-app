# DB v1.4 — 독자용 첫 챕터의 근거 설명 품질 개선

## 기존 원고에서 확인한 문제
가상의 생활 장면을 먼저 설명하는 원고는 읽기에는 쉽지만 어떤 출생월 계산에서 결과가 나온 것인지 파악하기 어렵다. `readerMechanical` 검사 통과는 문장 매끄러움과 전문감수 통과가 아니다. 99건 고정 표본 중 지원 31건이라는 수치를 품질로 오인해서는 안 된다.

## 실제 교정
- 편인/편재가 겉과 본기에 다르게 나온 丑 전환월: 시작부터 위치별 두 계산 분류의 뜻을 나누고, 본기가 겉을 극하는 관계와 전환월로서의 미확정 계절 우세를 설명한 뒤, 특정 선택의 장점과 놓칠 조건을 쓰도록 원고를 수정했다.
- 겉과 본기가 모두 정인인 辰 전환월: 두 개의 반대 성격을 꾸며내지 않고 하나의 배움 상징으로 읽으며 전환월에서 기운이 가장 강하다고 단정하지 않도록 원고를 수정했다.
- 두 원고에만 `editorialRevision`을 명시하고 조건, 분량, 계산 위치 설명, 전환월 한계, 강도와 사건의 과장을 기계 검증한다.

## 검증과 진실한 한계
기존 고정 표본 중 4건이 두 새 원고에 매칭된다. 31건의 초안 지원과 미지원 68건은 그대로다. 아직 27개의 나머지 원고 조합과 출생 연/시각 관련 문단의 깊이는 재검토해야 한다.
문장에 실제 명식 계산의 근거가 나온다고 해도 전문가의 명리 이론 감수와 사용자 심리·이력 관찰을 대신하지 않는다. 모든 문장은 draft-for-human-review/not-approved, 유료 API 호출 0회, 운영 앱 변경 없음.
