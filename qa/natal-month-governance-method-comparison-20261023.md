# 심화 사주 해석 QA — 출생월 사령·드러난 글자·중복 관계의 방법 비교

## 실제로 해결한 질문

"태어난 달의 본기", "절기 뒤 경과 일수에 따라 정하는 참고 사령", "달에 숨은 글자가 겉으로 드러난 관계"는 같은 계산이 아니다. 세 방법은 서로 다른 후보를 보여 줄 수 있다. 기본 글자나 정확한 투간이 확인되어도 **전통적 격국·신강약·성격·사건 판단이 자동으로 따라오지 않는다.**

`report-core-paid-natal-month-method-review.js`는 원래 명식, 절입 계산, 오행/기운 관계, 줄기 관계, 출생 지지 관계, 30일 참고표를 각각 **독립적으로 다시 계산하고 일치 검증**한다. 자료가 다르면 즉시 거절한다. 날짜별 참고표는 `diagnostic-not-adopted`, 사령·강도·우선순위는 모두 `not-assessed` 상태다. 기존 정상 유료 보고서에는 적용하지 않는다.

이 표는 개발용 고정 명식의 **계산·비교 결과**다. 참고 분일표 후보는 실제 사령 판정이 아니며, 특정 명식의 개인 성격이나 운명을 판정하지 않는다. "관계 5건"은 자료표에 나타난 관계 수일 뿐 인생 사건이나 작용 강도의 수치가 아니다.

## 서로 다른 방법의 정확한 범위

1. **월의 본기:** 달 지지의 기본 숨은 글자를 나타내는 구조적 분류. 실제 사령·격국·용신을 보장하지 않는다.
2. **분일 사령 참고표:** 한 출처의 약 30일 분배 표를 절입 경과 시간에 대입한 예시. 일부 이전 계절의 잔여 기운 후보는 원래 출생 숨은 글자 목록에도 없다. 따라서 이 후보를 실제 숨은 글자 ID로 승격하거나 사령이라고 확정하면 오류다.
3. **숨은 글자의 정확한 겉글자 대응:** 존재하는 글자가 드러난 자리와 정확히 같은지 계산한 관찰. 단순한 위치·문자 일치만으로 취격, 작용력 우세, 용신, 인생 결과를 판정하면 오류다.
4. **달의 지지와 겹치는 합·충 등:** 별도 출생 지지 관계 표의 후보들. 관계가 두 가지 이상이면 중첩 사실을 기록하고, 하나가 다른 관계를 제거하거나 효과를 결정했다고 단정하지 않는다.

## 추가 반례 검증: 태어난 날의 기준 글자와 다른 겉글자 분리 (2026-10-23)

기존 월지 숨은 글자 `exactExposure`는 원칙적으로 **해·달·날·시간의 모든 겉글자**와의 문자상 일치를 기록한다. 하지만 월지 지장간이 **다른 겉글자로 투출한 후보**를 검토하면서 태어난 날의 기준 글자까지 자동으로 포함시키면, 어떤 방법에서 실제 취격 대상으로 볼지 판단하기 전에 이미 사례를 잘못 합칠 수 있다.

이를 줄이기 위해 계산 원본은 변경하지 않고 `exactExposureScopeComparison`에 두 계층을 함께 유지했다.
- **전체 대응**: 네 겉글자 중 일치하는 곳(일간 포함)을 모두 보존
- **비(非)일간 대응의 비교 후보**: 해·달·시간의 겉글자에 맞는 경우만 별도 후보 목록에 표시
- **일간에만 맞는 대응**: 실제 관찰값이지만 다른 겉글자로 드러난 것과 구별해 표시

무료 CI가 **독립 계산된 다섯 개발용 명식**에 대해 확인한 결과:

| 개발용 입력 | 월의 숨은 글자와 전체 겉글자 일치 | 일간 제외 일치 | 일간에만 일치 |
| --- | ---: | ---: | ---: |
| 양력 1982-06-15 14:20 | 1 | 0 | 1 |
| 양력 1982-03-15 14:20 | 0 | 0 | 0 |
| 양력 1988-12-15 14:20 | 0 | 0 | 0 |
| 양력 1994-04-15 14:20 | 2 | 2 | 0 |
| 음력 1982-11-24 14:20 | 1 | 1 | 0 |

**기존 해석의 구체적 허점:** 첫 개발용 명식에서는 일간을 포함하면 월 숨은 글자가 겉으로 드러난 관계가 1건이지만, 일간을 제외해 비교하면 **0건**이다. 이 둘을 구분하지 않는 기능은 “월의 숨은 글자가 다른 겉글자로 드러났다”는 기술적 표현부터 혼동할 수 있다. 다른 모든 항목처럼 이것도 해당 고객의 기질이나 출세를 증명하지 않는다.

**문헌 검토의 한계:** 최원호·김나현·김기승(2024), 「인원용사의 연원에 관한 연구」([KCI](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART003050084))는 날짜별 사령과 월지의 투출에 의한 취격을 대조하지만, 이 수치 검사의 '일간 제외' 자체를 해당 논문만으로 **승인된 최종 판정 규칙**이라고 선언할 수 없다. 고전 원전·선택 학파·반례가 확인될 때까지 **두 범위를 모두 기록**하며 격국·용신·우열에 적용하지 않는다.
