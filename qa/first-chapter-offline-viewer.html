첫 사주 보고서 원문 열기

이미 생성된 유료 원본을 추가 과금 없이 여는 로컬 뷰어입니다. ZIP 파일 또는 압축을 푼 .enc 파일을 선택하세요. 모든 복호화는 이 PC의 브라우저 안에서 진행하며, 파일이나 키를 서버에 전송하지 않습니다.

암호화된 ZIP과 원래 키를 선택한 뒤 ‘내 PC에서 원문 열기’를 누르세요.

중요: 새로 만든 API 키로는 과거 암호화 파일을 열 수 없습니다. GitHub에 저장된 Secret 값 자체는 다시 표시할 수 없습니다. 원래 키를 잃어버렸다면 이 뷰어만으로 복구할 수 없으며, 암호화 자료를 공개 로그에 출력하면 안 됩니다.

오프라인 암호화 라이브러리: scrypt-js (Richard Moore, MIT). 외부 스크립트나 네트워크 요청을 사용하지 않습니다.
