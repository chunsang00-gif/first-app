# 실제 유료 보고서 제공량의 전후 일치 검증

2026-10-29. 작업 브랜치: `fix-paid-qa-fact-bindings-20261014`. 운영/main 변경 금지. 유료 API 0회.

## 왜 필요한가

QA11~QA15에서 확인한 상품 계약은 12장, 28개 항목 정의, 현행 정책상 최대 22개 활성 가능이다. 출생정보에 따라 실제 계획은 9~11장, 19~20개 활성 가능한 항목 상한으로 더 줄 수 있다. 사전 상한은 **실제 모델이 작성한 분량**이 아니며, 비필수 문단은 `null`로 생략될 수 있다.

기존 출생정보별 무료 미리보기는 '생성 가능한 상한'을 보여줬지만, 완성 원고 단계에서 **실제 작성된 문단**과 이 상한의 일치 관계를 별도로 집계해 고객에게 안내하지 않았다.

## 적용 사항

- `report-delivery-scope.js`: 실제 결과물의 장 순서, 계획된 장 ID, 정확한 topic ID, 허용된 `use-primary` / `use-verified-fallback` 모드, 출생정보별 기준 문단(anchor) 포함, 본문/소제목 배열 길이, 문단 비어 있음 여부를 서버가 계산한 `report-analysis-guidance.preflight`와 비교한다. 인용 근거/명리 의미의 전문가 승인은 별도이고 이 모듈은 **수량과 배치의 구조적 무결성만** 검증한다.
- `report-release-gate.js`: 유효한 실제 계산 packet이 있는 원고의 `deliveryScope`를 추가하여 누락/허위 항목을 `inconsistent-delivered-topic-scope`로 분류한다. 임의로 독자 가치나 출시 여부를 승인하지 않는다.
- `report-server-contract.js`: 최종 보고서 `status:'ready'` 직전에 구조 집계를 반드시 실행하고, 실제 완료된 항목이 출생 계산의 허용 범위를 넘거나 계획과 어긋나면 `qa.pass=false`로 바꾸어 **`status:'rejected'`로 차단**한다. 이 동작은 합성 mock뿐 아니라 실제 서버의 전체 계약과 같은 코드 경로다.
- `report-renderer.js`: 화면 상단에 '실제로 작성된 분석: N개 장 · M개 세부 풀이' 문구 추가. 세부 항목 ID가 없는 이전 저장 원고는 숫자 0을 강제로 표시하지 않는다. 목표 12장·35항목을 확정 제공했다고 주장하지 않는다.
- `result-dashboard-tests.js`: 실제 문단 수 12/12, 장이 빠진 9/9, 이전 자료에서 개수 숨김을 렌더링 검증.
- `report-delivery-scope-tests.js`: 실제 4개 계산 명식의 9장/19항목 상한, 10장/19, 10장/20, 11장/20에서 **실제 남은 한 문단씩**을 구별하여 집계한다. 비활성 `money.risk` 허위 작성, 출생 근거 기준 문단 누락, 장 순서·내용 불일치, 중복 세부 주제, 비어 있는 문단을 거부한다. 이 테스트는 사전 조건을 확인하는 합성 문장이지 전문 명리 해석 검증이 아니다.
- `smoke-test.js`: 기존 로컬 모의 모델이 비활성 6개 항목을 채워도 통과하던 버그를 바로잡아 실제 선택 규칙상 허용된 항목만 반환하도록 수정했다. 명리 계산값은 바꾸지 않았다.

## 아직 해결되지 않은 유료화 차단 원인

이 검사는 이미 있는 문단이 **사전 범위 밖의 거짓 분량인지** 판별할 뿐 **35개 독립 유료 해석**을 만들지 않는다. 12장/28항목 정의와 실제 최대 22개 활성 상한은 불변. QA5의 실유료 연구 문단 `null` 문제, AI 원문의 내용 충실도/중복, 전통 해석 우선순위, 사용자 관점의 지불 가치·인간 전문 검수, 결제 권한/환불 정책은 여전히 미해결이다.

후속 작업은 다수의 새로운 QA 번호보다 **실제 과금 없이 기존 저장된 제공자 원본에서 반복·근거 부족 문제를 분석하고, 생성할 수 없는 항목에 고정 요금을 약속하지 않는 정식 상품 계약**으로 이어갈 것. 필요할 때만 새로운 명시적 유료 호출 승인 요청. 35개를 채우기 위해 기존 6개 금지 문단을 허위 작성하거나 검증기를 완화하지 말 것.
