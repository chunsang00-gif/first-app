# 사주 첫 챕터 미지원 조합 자동 집계

대상: 기존 99개 고정 양/음력 검증 표본 중 검토 초안이 없는 경우. 실제 사용자의 분포 또는 시장 규모를 추정하지 않는다.

`report-core-rule-opportunities.js`는 기존 검증된 사실과 내부 편집 작업지시서에서 **출생월 십성쌍, 계절 상태, 월 겉글자와 본기 오행 관계**를 추출해 미지원 분류별 개수를 집계한다. 실제 미지원 해석 후보를 정할 때 한 두 사람 사례만 붙잡는 일을 줄인다.

미지원이라고 해서 자동 생성 문장을 유료 고객에게 보여주지 않는다. 이 집계로 검토 후보를 정한 뒤, 해당 월지의 본기 십성 및 출생일 기준이 성립하는 새 편집 원고를 별도 작성하고 유효한 실제 명식 테스트를 고정해야 한다.
