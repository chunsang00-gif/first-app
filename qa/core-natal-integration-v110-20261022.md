# v1.10 — 공통 원국 종합 비교 시스템

## 기존 문제
v1.9의 네 기둥 통합 해석은 사람이 작성한 검토 원고 6종으로 구성됐고, 고정 99개 검증 사례 중 4개에만 해당했다. 나머지 초안 지원 명식에는 해·달·날·시간을 한 문단으로 연결해 읽을 수 있는 근거 안내가 없었다. 이 문제가 독립 원고를 계속 손으로 추가하는 방식으로 반복됐다.

## 이번 변경
`report-core-chart-integration.js`를 도입했다. 우선 기존 월간·월지본기 원고가 존재하는 경우에만 실행하며 다음을 원국에서 직접 재계산·검산한다:

- 태어난 날의 중심 오행과 이를 기준으로 한 출생 해·달·시간 천간 십성
- 달의 겉글자와 달의 대표 지장간을 별개의 근거로 구별
- 연간·시간 십성이 월간과 동일 세부 분류인지, 같은 계열의 다른 분류인지, 다른 계열인지
- 핵심월/전환월과 계절 오행의 방향. 계절 전환월은 실제 사령·전체 강약 결정을 유보
- 숨은 동일 오행 글자의 원국 출생 위치와 공식 천간·지장간 출처
- 전통 지지 관계표의 충·형·해·파·육합 및 3지지 관계표의 해당 여부. 사건, 합화, 손실 또는 실제 운세 효과는 추정하지 않음

사람이 집필한 기존 네 기둥 통합 문단이 선택되면 자동 조합 문단을 중복으로 붙이지 않는다. 출생시간 미상이라면 시간에 관한 종합 문단을 생성하지 않으며, 아예 월별 독자용 원고가 없는 명식에는 독자용 문단을 만들지 않는다.

## 자동 조합 문장에 대한 투명한 처리
이 문단은 전문 명리 작가가 개별적으로 감수한 풀이가 아니다. `review.chartSynthesis.editorialStatus = machine-composed-review-only`, `releaseVerdict = not-approved`, `humanReviewRequired = true`, `apiCalls=0`으로 분리 관리한다. 계산 검증은 원문이 고급스럽거나 실제 상담 수준이라는 의미가 아니다.

## 고정 테스트 확인
- 99건 중 독자용 첫 챕터 초안: **31건**, 미지원: **68건** — 두 값은 바뀌지 않음
- 기존 수작업으로 쓴 종합 원고 적용: **4건**
- 새 계산 근거 자동 결합 검토 문단: **27건**
- 출생시간 변경 시 달 중심 원고는 유지되지만 종합 근거 문단은 달라짐
- MBTI/분석 대상 연도 변경이 원국 근거 문단에 영향을 주지 않음
- 연간, 출생시간, 계절, 뿌리, 지지 관계표 근거를 조작하면 선택이 실패하도록 검사
- 무료 GitHub Actions 검사, 유료 API 호출 없음, 운영 브랜치 또는 기존 생성 파이프라인 변경 없음

## 다음에 필요한 실질적 품질 기준
자동 조합으로 나열된 분류가 실제 해석의 근거를 충분히 설명하는지 명리 검수, 의미 중복 검수 및 독자용 통독 검수 필요. 68개 지원되지 않는 명식에 대해선 개별 원고를 무작정 늘리기보다 전통 해석의 규칙·학파·증거 조건을 먼저 합의한 뒤 검증 가능한 종합 해석 체계를 별도 구축해야 한다.
