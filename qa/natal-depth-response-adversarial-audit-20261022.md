# 심화 응답 검수: 추가 무료 반례 감사

## 범위
정상 결제 보고서에는 아직 적용하지 않은 `natal_depth` QA 전용 응답 검수의 **거짓 통과 및 허위 차단 위험**을 점검했다. 표본은 실제 AI가 작성한 출력이 아니라 고정 원국에 맞춘 가상 JSON 응답이다. 모든 단계에서 유료 API 호출은 0이다.

## 실제 고친 취약점
기존 출생 해·시간 십성 역할 검사는 문장 어디에든 올바른 의미 단서가 있으면 그 위치가 근거에 맞는다고 판정할 수 있었다. 예를 들어 해의 정재 뜻을 설명하는 문장에 정인의 잘못된 의미를 먼저 쓰고 뒤에 올바른 정재 표현을 덧붙인 경우를 차단하지 못할 수 있었다.
`report-core-paid-natal-depth-role-check.js`에 다른 십성만을 가리키는 **분명한 표현을 동시에 사용했는지** 비교하는 보수적 차단 규칙을 추가했다. 문장 하나에서 해·시간을 함께 비교한다면 표현 단서만으로 어느 출처에 귀속됐는지 확정할 수 없어, 이 검사는 전문 검수를 대체하지 않는다.
`report-core-paid-natal-depth-response-gate.js`는 출처 근거의 `condition` 및 `limit`가 비어 있지 않다는 사실뿐 아니라 가상 조건과 해석의 한계를 실제로 서술하는지도 확인한다.

## 재현 결과
기존 부정 응답 18종에 다음 4종을 추가했다: 해의 정재 뜻을 정인의 잘못된 표현과 섞기, 시간의 식신 뜻을 상관의 잘못된 표현과 섞기, 적용 조건을 일반적 권고 문장으로 바꾸기, 한계 문장을 근거 없는 응원 문장으로 대체하기. 모든 부정 응답 **22종** 차단. 정상 모의 응답 1건 및 추가 심화가 없는 `null` 1건 허용. 전체 `npm test`와 `npm run smoke` 통과.

## 유료 출시 차단 상태
이 검수는 정확한 뜻의 일부 표현과 기계적으로 검사 가능한 출처·문장 구조만 확인한다. 실제 AI 생성 심화 보고서의 전문적 명리 판단, 자연스러운 한국어, 독자 가치 및 12개 챕터 전체 중복은 검증하지 않았다. `releaseVerdict = not-approved`; 실사용과 운영 브랜치 변경 없음.

다음 안전한 단계는 단 한 차례의 명시적으로 허가된 유료 QA 생성에 앞서 입력 원국, 기존 기본 풀이, QA용 심화 문단의 근거 목록을 고정하고, 생성 응답 전체를 위 검사에 통과시킨 뒤 전문 감수 자료로 보관하는 것이다. 호출 비용 없이 준비 과정까지 확인할 수 있지만, 무료 자동 테스트만으로 유료 원문 품질이 승인되지는 않는다.
