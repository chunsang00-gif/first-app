# 사주 해석 DB v0.6 — 시간 기둥에 따른 검토용 원고 비교

## 목적
기존 DB v0.5는 음력 1982-11-24의 **서로 다른 시간 14:20과 20:20**에서 같은 독자용 원고를 반환했다. 출생 달과 날의 계산이 같아도 시간 기둥에 기록된 십성이 다를 수 있으며, 그 차이가 뒷부분에만 계획값으로 남고 독자에게 전달되지 않았다.

## 적용된 검증 조건
- 14:20 = 출생 시주 癸未, 시간 천간 편인, 월간 편인: **동일 분류의 다른 두 위치**로 설명한다.
- 20:20 = 출생 시주 丙戌, 시간 천간 상관, 월간 편인: **다른 계열의 두 의미**로 설명한다.
- 둘 다 출생일 천간 乙, 출생월 천간 癸, 검토된 출생월 규칙과 정확한 시주가 일치해야 한다.
- 출처는 `natal.hour.stem` 및 `natal.month.stem` 두 개가 필수다. 위치·십성·원본 계산 일치 여부는 기존 `wholeChart.build`에서 독립 검증한다.
- 출생시간을 모르면 **시간 문단 자체를 만들지 않는다**. 다른 달·일·시주와 미검토 월별 규칙에는 무조건 적용하지 않는다.

## 독자에게 전달할 실제 차이
두 시간 사례는 동일한 출생월/일 해석은 유지하되, 시간 천간의 검증된 상징 차이만 독립 소제목에서 설명한다. 시간 분류의 단순 개수로 성향 강약을 판정하지 않는다. 시간주가 미래 직업이나 자녀 등 구체적 인생사에 영향을 준다고 예측하지 않는다.

## 기술 보호
- `report-core-hour-context.js`: 검증된 시간·월간 십성과 정확한 위치를 충족하는 편집 후보만 선택. 허위 십성/오염된 출처 DB 거부.
- `report-core-knowledge-engine.js`: 기존 사주 해석 계획을 교체하지 않고, 유효할 때만 `paragraphs.hour` 추가.
- `report-core-reader-editorial.js`: 신규 문단도 기존 문장 품질 검사 범위에 포함.
- `report-core-knowledge-tests.js`: 14:20/20:20/시간미상 구분, 부정확한 출처 차단, MBTI·연도 독립성, 기존 계획 보호.
- `report-core-knowledge-coverage.js`: 새 시간문단 2건과 글의 재사용 정도를 99건 고정 표본에서 별도 측정.

## 미해결 및 릴리스 판정
이 문장은 계산상 의미 차이를 독자용 문장으로 풀어 준 **편집 검토 후보**다. 시간주가 생활영역·인생 시기·기질의 크기를 뜻한다는 추가 명리학적 검토는 아직 없다. DB의 전체 조합 커버리지는 거의 증가하지 않으며 문장 깊이도 사람 검증 전이다. **유료 노출 미승인, 운영 앱/기존 계산/유료 요청 경로 변경 없음, 모델 API 호출 0회.**
