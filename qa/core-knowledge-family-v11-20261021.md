# 첫 챕터 명리 구조별 편집 후보 확장 — v1.1

## 2026-10-21 현재 계산·집필 분리 정책
기존 v1.0은 출생월 근거를 검산한 99개의 고정 표본에서 23건만 독자용 첫 챕터 검토 초안을 제공했다. 본 작업은 미지원 명식 중 같은 구조가 서로 다른 출생월에서 반복되는 4개 그룹을 추가하고, 월에 맞는 독립 장면과 판단 조건을 작성했다. 이것이 전문가 검증을 마친 사주풀이 또는 유료 출시 가능성을 뜻하지 않는다.

## 적용한 네 구조
| 가족 | 월지별 검증용 출생월주 | 상징 구조 | 주의점 |
|---|---|---|---|
| 식신 / 상관 | 子 壬子 · 亥 癸亥 | 같은 오행, 서로 다른 결과 표현 분류 | 표현 능력이나 성공을 측정하지 않음 |
| 편관 / 편관 | 寅 甲寅 · 卯 乙卯 | 같은 분류가 겉과 속에 반복 | 부담·강약을 두 배로 판정하지 않음 |
| 비견 / 편재 | 申 丙申 · 酉 丁酉 | 겉에서 속으로 극하는 방향 | 재물 손익이나 실제 지출을 예측하지 않음 |
| 정인 / 정관 | 未 辛未 · 辰 庚辰 | 본기가 겉을 생하는 전환월 | 본기를 실제 사령 또는 계절 우세로 확정하지 않음 |

## 코드 및 QA
새 가족은 `report-core-knowledge.json`의 `familyRules`에 **4개 그룹과 각각 2개의 월별 variant**로 저장된다. 기존 `report-core-rule-families.js`의 구조 감사를 통과한 조건에서만 `report-core-knowledge-engine.js`가 원래 계산한 십성·월지·계절·오행 관계를 독립 대조하고 `draft-for-human-review`를 반환한다. 불일치하면 과거처럼 null reader와 not-covered를 유지한다.
원고는 실제 성격 평가가 아니라 독자를 위한 전통 상징의 설명 후보이며, 시주와 다른 출생 위치 등 미검토 근거는 추가하지 않는다. 동일 어구 반복 검사는 기계적인 수준에 불과하며 전문가가 문장을 읽어보는 과정은 별도로 필요하다.

99건 커버리지·17개 가족 독립 원고·4개 새로운 구조·재사용 여부·MBTI/대상연도 분리·기존 오류 차단·무료 smoke test를 검증한다. 유료 API 호출 0회, 기존 원국 계산 엔진 및 운영 브랜치 변경 없음, 독자에게 배포하지 않음.
