# v1.3 원국 교차 해석 확대 및 출생시간 반례 검사

v1.2에서 99건 합성 고정 달력 표본 중 첫 챕터 초안은 31건이었으나, 연간·월간·월지 본기의 세 위치를 연결하는 원고는 5건이고 시주 조건부 원고는 2건뿐이었다.

## 추가된 검토 후보

- 연간·월간·월지 본기의 세 위치를 함께 읽는 개별 원고 다섯 건. 1982-12-15, 2018-06-15, 2018-05-15, 2024-09-15, 1994-06-15의 실달력 명식에서 년/월/본기 십성을 각각 검산한다.
- 출생시간만 14:20과 20:20으로 변경한 1988-12-15, 1994-08-15의 두 명식에 각각 두 종류의 문단을 작성했다. 시주 미상인 경우 시주 단락은 무조건 생략한다.
- 가족 규칙으로 확장한 출생월 조합도 정확한 월간, 일간, 시주와 일치한다면 기존 시주 비교기에서 선택할 수 있도록 했다.

## 판정 원칙

원국 출생위치·십성·상대 분류를 independently 계산한 기존 원장과 대조한다. 시주만 바뀌면 월별 문단과 연·월·본기 세 위치 문단은 동일해야 하며 시주 문단만 서로 다르다. 명리 기호의 중복으로 능력이나 기운의 세기가 늘었다거나 관계/돈/직업의 사건이 생긴다고 단정하지 않는다.

출생월 중심으로 만든 총 원고 지원은 31/99로 그대로 둔다. 이번 작업은 검증된 추가 근거가 붙는 초안의 양만 늘리는 변경이다. 검토용 문장은 전문 감수, 통독 편집, 실제 유료 보고서 품질 승인과 무관하다. 계산 엔진, 기존 유료 AI 경로, 운영 브랜치에 손대지 않으며 테스트에서 API 사용량은 0이다.
