## 해석 DB 확장을 위한 기준

1. 새로운 해석 자료를 넣을 때 단순히 규칙 이름만 등록하지 말고, **일간·실제 월간·월지 본기·계절 방향**을 동시에 만족하는지 검증한다.
2. 본문의 각 추가 결론에 **월간/월지 외의 실제 출생 위치**가 필요하다면 해당 자료를 확인·인용하는 규칙을 따로 둔다.
3. 시간·연주·일주의 차이가 있다고 억지로 다른 성격을 만들지 않는다. 대신 그 차이가 무시되는 경우를 측정하고, 전통 해석상 의미가 입증되는 차이만 독립 문단으로 작성한다.
4. 전문가/사람이 검토하지 않은 가상 장면과 조언은 최종 보고서로 승인하지 않는다.
5. 커버리지 숫자만 키우려고 '모든 사주에 적용되는 성격'이나 일반적인 준비 조언을 넣지 않는다.
6. API 호출을 또 하기보다, **DB 내용의 명리적 타당성·개별화 정도·실제 한국어 자연스러움**을 검증하며 확장한다.
