# DB v1.7 — 17개 가족 변형 원고에 명식별 근거 설명 추가

## 실제 발견한 오류
`family-bigeon-jeongin-resource-v1`의 亥월 원고는 계산 조건 `seasonToDayRelation=resource`와 달리 계절 오행이 일간 오행과 '같은 계열'이라고 기술했다. 기존 자동 테스트는 명리 계산 수치만 검증하고 **한국어 설명의 방향이 실제 계산과 모순되는지** 검증하지 못했다. 해당 원고를 '계절 오행이 태어난 날의 오행을 생하는 관계'로 바로잡았다.

## 개선 방식
가족 변형 17종 각각에 편집자가 작성한 별도의 `evidenceLead`를 배치했다. 독자용 초안의 첫 문장은 항상 태어난 달의 겉글자와 안쪽 대표 글자를 밝혀 시작하며, 오행의 방향과 핵심월/전환월의 계절 관계를 그대로 설명하고, 능력·행동·사건·강약에 대한 부당한 확대를 삼간다.
그 뒤에는 가족 공유 원고와 월별 생활 예시가 이어진다. 즉 각 17종의 **도입 설명을 교정**한 것이지 나머지 본문·장점·단점·마무리 문장 전체가 전문 감수됐다는 주장은 아니다.

## 재발 방지
`report-core-rule-families.js`에서 분류 `visible`·`hidden`, 계산상 월지본기-월간 방향, 계절-일간 방향이 실제 도입 설명에 있는지 검증한다. 위조된 계절 생극 또는 잘못된 전통 분류를 쓰면 가족 규칙 감사에서 실패한다. 실달력 99건 고정표본에서 17개의 가족 원고가 각 하나씩 선정되며 개별 원고 14건과 함께 기존 총 31건의 초안 지원을 유지한다.

이는 단순한 문자열·구조 검사이지 한국어 의미 전체를 보장하는 전문 감수가 아니다. 금전적인 API 호출 및 운영 브랜치 변경 없음. 전체 유료 보고서 품질 미승인.
