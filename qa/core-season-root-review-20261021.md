# 핵심해석 v0.7: 계절·출생 위치·같은 성질의 숨은 글자

## 이번 변경의 근본 목적
DB v0.6은 월별 의미, 출생월·일 관계, 시간에 보이는 천간만 따로 풀었다.
그러나 이미 계산된 '태어난 날을 기준으로 같은 오행에 속하는 지장간'의 **정확한 위치**를 해석 초안에 쓰지 않았다.
이번에는 기존 계산과 검증 원장을 그대로 사용하며, `seasonRootRules`에서 검토된 조건만 좁게 설명한다.

## 검토 표본과 원장
- 음력 1982-11-24, 양력 1983-01-07, 월지 丑(겨울 전환월), 일간 乙, 일지 未.
- 14:20 = 癸未: `natal.day.hidden.乙`와 `natal.hour.hidden.乙` 두 위치 확인.
- 20:20 = 丙戌: `natal.day.hidden.乙` 한 위치만 확인.
- 출처: `facts.seasonalEvidence`, `facts.qiEvidence`, `facts.stemConnections` 및 해당 `natal.*` 항목.
- 둘 모두 월지 丑 자체에 乙이라는 동일 오행의 숨은 글자가 있다고 주장하지 않는다.
- 계산된 '출현 위치의 수'는 **기운의 크기, 실사령, 득령, 용신, 충에 의한 뿌리 소멸**을 입증하지 않는다.

## 선택 조건
1. 이미 검증된 월간 편인/월지 본기 편재 규칙 + 丑월 + 乙일간 + 未일지.
2. `report-seasonal-evidence.evaluate`로 월 계절·전환월을 별도 재확인한다.
3. `wholeChart.build`에서 검산된 숨은 글자의 정확한 위치(출생일/시간)와 대조한다.
4. 독자용 문장은 검토된 두 **정확한 시주**의 `variants`에서만 선택한다. 출생시각 미상, 다른 시주, 다른 월 규칙은 미지원이다.
5. 생활영역 예측·성격 단정 금지. 사람의 명리학적 편집 검토 전 유료 노출 금지.

## 테스트·릴리스
- 기존 계산 엔진/유료 생성 경로/운영 배포 변경 없음.
- 출생시간 14:20 대 20:20의 출처 및 초안 차이, 시간 미상 차단, 계절·뿌리 위조 거부, 직장·금전 단정 금지 테스트.
- 고정 99건에서 계절·뿌리 보조 문단 **선택된 초안 수**만 따로 집계.
- `apiCalls:0`, `releaseVerdict:'not-approved'`. 검증된 계산 위치를 풀어썼다는 뜻이지 유료 해석 품질 합격은 아니다.
