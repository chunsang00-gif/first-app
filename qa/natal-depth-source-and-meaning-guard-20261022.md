# QA 심화 응답: 4기둥 근거 문자 잠금 + 독자용 뜻 검증 (2026-10-22)

## 재발 방지 대상
기존 15개 반례 테스트는 인용 출처 ID의 누락이나 중복, 전문용어, 생활 사건 예언을 차단했다. 하지만 **올바른 출처 ID를 붙이면서 내부 해석 문자열에 엉뚱한 십성을 적어도** 통과할 수 있었고, **독자용 문장에서 연간과 시간의 뜻을 실제 십성과 다르게 쓰는** 가상 응답이 정상 사례로 통과했다.

## 이번 보강
- `report-core-paid-natal-depth-fact-lock.js`: 실제 provider payload의 연간·월간·일간·시간 행에서 글자·십성·출처 위치·전통 상징 한계를 확인하고, 위치별 계산 내용을 하나의 변경 불가능한 내부 문자열로 생성한다.
- `report-generation-request.js`: QA 전용 `natal_depth.basis.interpretation`을 엄격한 JSON 스키마의 단일 enum에 고정. 응답 복원 직전에도 정확히 같은 문자열인지 검사한다.
- `report-core-paid-natal-depth-response-gate.js`: 올바른 ID만 인용하면서도 내부 해석을 엉뚱하게 바꾸는 것을 차단한다.
- `report-core-paid-natal-depth-role-check.js`: 독자용 문장에서 출생 **해**와 **시간**에 귀속시킨 설명을 해당 위치의 실제 십성 뜻에 대조한다. 보수적인 한국어 표현 신호 검사이므로, 자동 전문 명리 감수나 고급 원문 품질 보증이 아닌 QA 안전망이다.
- 기존 테스트에서 양력 1982-06-15 오후 2:20 사례의 실제 연간 `정재`와 시간 `식신`을 `배움·조언` 및 `새로운 제안`으로 잘못 설명하던 정상 가상 원문을 수정했다. 동일한 잘못된 설명 두 개를 별도 탈락 반례로 추가했다.
