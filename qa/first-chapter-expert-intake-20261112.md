# 유료 첫 장 — 출생시간 반례와 전문가 판단 접수 (2026-11-12)

**현재 상태: 전통 해석법 미채택 / 유료 해석 원고 미승인 / 판매 차단 유지.**

지난 명리 심화 검토는 실제 계산된 글자와 고전 출전이 달라진다는 점은 보였지만, 그 차이가 개인의 삶에서 어떤 뜻인지 전문가가 채택하지 못해 유료 가치 심사에서 탈락했다. 이번 작업은 기존 다섯 질문을 반복해서 새 설명을 덧붙이는 대신, 동일 생년월일의 출생시간 변경이라는 반례를 전문가 답변의 필수 항목으로 묶었다.

## 로컬에서 실행

개발 PC의 저장소에서 명령: node report-first-chapter-expert-intake.js

검증용 명식 음력 1982-11-24 14:20(乙未日 癸未時)과 20:20(乙未日 丙戌時)을 비교한다. 두 사례는 출생 해·월·일의 검증 계산값은 같지만 시간 기둥이 달라, 『三命通會』에서 확인해야 할 해당 시각의 문구도 달라진다. 정확한 출처가 있다는 사실은 성격·직업·재산·미래 사건에 관한 개인 판단이 아니다.

## 전문가 답변에 반드시 포함할 항목

1. 어느 전통 해석 체계와 원전을 왜 선택하는가?
2. 태어난 달의 기본 글자, 노출된 다른 글자, 사령 진단 사이에 어떤 조건을 우선 적용하는가?
3. 해·날·시의 관계를 어떤 규칙으로 연결하며 14:20과 20:20에서 무엇이 바뀌는가?
4. 선택한 규칙을 뒤집는 반례와 제외 조건은 무엇인가?
5. 단순 글자 풀이 외에 개인별 새 해석을 정당화할 수 있는 독립 근거는 무엇인가?

각 질문에 결론(conclusion), 원문 주소(citationUrl: https), 적용 규칙(applicationRule), 반례(counterexample)를 답해야 한다. 출생시간을 모르는 사례와 서로 다른 출생일을 같은 반례로 묶지 않는다. 응답 원본과 실제 사용자 입력은 공개 저장소로 업로드하지 않고 개인 장치에만 보관한다.

## 승인 경계

screen 함수는 답변 구조와 두 명식의 일치만 검사한다. 형식이 모두 맞더라도 전문성·원문 정확성·해석 우선순위·독자 가치 검증은 자동 인증되지 않으며 유료 보고서 작성, 결제, 배포가 허가되지 않는다. 별도 명리 전문가 판단과 실제 유료 원고의 편집 검수가 필요하다. 이전 QA 및 정상 유료 작성 경로는 변경하지 않는다.

## 형식 검사의 중복 답안 차단 (2026-11-12)

기존 접수 검사는 동일한 장문 문장을 결론·적용 규칙·반례에 그대로 붙여 넣거나 다섯 질문을 통째로 복사해도 형식상 완료로 처리했다. 이제 **한 질문의 세 필드가 같은 내용이거나 서로 다른 질문의 답변 세트가 완전히 재사용되면 접수를 불완전으로 표시**한다. 질문에 따라 실제로 다른 근거를 설명하도록 유도하기 위한 최소한의 구조 검사다.

이 검사에 통과해도 내용의 진위, 출전의 원문 대조, 전문 자격 또는 유료 고객 가치가 증명되는 것은 아니다. 특정 문장을 고치거나 글자 수만 늘려 자동으로 판매가 열리는 경로는 없다. 정상 유료 API·결제·운영 경로는 변경하지 않는다.
