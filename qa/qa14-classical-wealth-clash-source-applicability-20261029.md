# QA14 — 『자평진전』 원문과 금전 위험 독립 슬롯의 정확한 적용 한계

검토일: 2026-10-29. 공개된 고전 원문에 대한 **수작업 문헌 확인**과, 10개 합성 사주의 **실제 계산 관계**를 비교했다. 이것은 고전의 최종 격국 판정 또는 재물 예측이 아니다. 모델 호출 0회, 운영/결제/유료 생성 코드 변경 없음.

## 원문 세 곳과 확인된 해석 경계

| 고전 원문의 장 | 공개 원문 링크 | 이 연구에서 확인한 범위 | 자동으로 도출할 수 없는 주장 |
|---|---|---|---|
| 『자평진전』 권1 「칠, 논형충회합해법」 | https://www.donglishuzhai.net/chapter/3720.html | 충·합·회합은 중첩될 수 있고 별도의 조합에 따라 해석상 관계가 달라질 수 있음 | 출생 지지 한 쌍이 충이면 그 안의 특정 재성에 피해가 발생함 |
| 『자평진전』 권1 「팔, 논용신」 | https://www.donglishuzhai.net/chapter/3721.html | 출생월을 해석 출발점으로 보고 연·월·일·시의 여러 요소를 함께 비교할 필요가 있음 | 출생월의 한 글자나 재성의 존재만으로 격국/용신의 최종 선택이 끝났음 |
| 『자평진전』 권2 「십칠, 논묘고형충지설」 | https://www.donglishuzhai.net/chapter/3730.html | 진·술·축·미의 충이 언제나 재물창고를 연다는 도식적 주장을 비판하며 재성의 오행, 투간, 월령을 구분함 | 진술충/축미충이 있으면 재물 수입이 증가하거나 반대로 손실이 생김 |

특정 고전의 시대적 해석은 현대 경제·투자 사건의 인과관계를 입증하는 자료가 아니다. 고전에는 전통적인 길흉 서술이 있어도 출생시각만으로 실제 소득·재산·손실을 검증할 수 없다. 원문 전자 판본의 장 구성과 주석은 판본별로 일부 차이 날 수 있으므로, 출처를 고정한 *적용 조건의 후보*만 기록했다.

## QA13 후보 네 명식과 원문 세부 조건

| 합성 명식 | 실제 출생 사주 네 기둥 (연·월·일·시) | 재성 숨은 글자와 충이 겹친 사례 | 확인된 다른 지지 관계 | 고전 특정 예시와 일치 |
|---|---|---|---|---|
| **음력 1982-11-24 14:20** | 壬戌 癸丑 乙未 癸未 | 축미충, 겹치는 출처 4개. 재성 己가 겉글자에 별도로 드러나지 않음 | 형·파 관계 후보 | **아니오** |
| **양력 1994-01-15 14:20** | 癸酉 乙丑 辛丑 乙未 | 축미충, 겹치는 출처 2개. 재성 乙은 월·시 겉글자에도 존재 | 형 관계 후보 | **아니오** |
| **양력 1994-04-15 14:20** | 甲戌 戊辰 辛未 乙未 | 진술충, 겹치는 출처 1개. 재성 乙이 시 겉글자에 존재 | 형·파 관계 후보 | **아니오** |
| **양력 1994-05-15 14:20** | 甲戌 己巳 辛丑 乙未 | 축미충, 겹치는 출처 1개. 재성 乙이 시 겉글자에 존재 | 형·파 관계 후보 | **아니오** |

- 나머지 6개 명식에는 원국 충이 없어서 QA13 재성 위치와 충 연결 후보도 없었다.
- 네 명식의 8개 **후보 행**은 모두 *진술충/축미충(사묘고 충)*이었다. **후보 8개 ≠ 고전 재물 해석이 8건 성립**을 뜻하지 않는다.
- **같은 위치에 형·파 관계 후보가 겹친다.** 이는 서로 경쟁하는 해석의 우선순위가 검증되지 않았다는 뜻이며, 형·파의 실제 효력이 성립한다고 판단한 것은 아니다.
- 고전의 특정 예인 **갑일·진월·무토가 겉에 나타난 진술충의 재성 사례**, **기일·진월·임수가 겉에 나타난 진술충의 반대 사례**와 계산 조건이 동일한 명식은 **0개**다. 그 사례의 해석을 이식해서는 안 된다.
- 숨은 글자와 겉글자의 일치가 확인되더라도 그것만으로 월령·격국·해석상 우선순위·그 글자의 실제 영향은 정해지지 않는다.

## 적용한 QA 코드

- `report-qa14-classical-wealth-clash-scope.js`: 현행 `report-qa13-money-risk-independent-source.js`의 실제 출처-지지 후보를 받아 여섯 육충 **정확한 쌍**만 허용하고, 진술/축미·자오/묘유·인신/사해를 구분. 해당 재성 숨은 글자의 다른 겉글자 출현, 출생월 포함 여부, 연결 자리의 형·파·합 후보, 완성된 삼합/방합 표를 별도로 기록. 고전 본문 특정 예의 조건을 확인하되 최종 격국·금전 결과는 **항상 미검증**으로 둔다.
- `report-qa14-classical-wealth-clash-scope-tests.js`: 합성 명식 10개에서 원본 계산과의 일치·육충 아닌 자유 조합 거부·출처 이식 금지·고전 특정 재성 예 일치 0건·현재 유료 `money.risk` `state-limits` 유지. 원고를 생성하지 않음.
- 첫 테스트에서 **자유(子酉)가 같은 방위 분류라는 이유만으로 육충처럼 허용되는 잘못된 조건**이 드러나 정확한 6개 충 쌍으로 교정했다. 원본 `report-branch-relations` 계산은 그대로이고 **연구 범위 검사기의 결함만 고쳤다**.
- 성공 확인용 GitHub Actions/커밋은 인수인계 문서와 Actions 결과 참조. 테스트는 `npm test` 통합, `npm run smoke` 변경 없음.

## 유료 상품의 실제 결론

**QA14는 '금전 위험 유료 문단을 추가해도 된다'는 승인과 반대되는 결과다.** 고전 원문을 조사한 뒤에도 확인된 결론은 *여러 충·형·파 후보의 실제 존재*이며, 재산의 안전성이나 손실 가능성을 새롭게 확정할 수 없다. `money.risk`는 계속 `state-limits`, `report-wire`의 해당 슬롯은 `null`로 남는다.

현재 12개 정의 장/28개 정의 질문/22개 활성 가능 상한/목표 35개 사이의 공백은 **그대로**이다. 다음에는 첫 장과 위험 항목의 QA를 되풀이하기보다 **실제 결제 전에 가능한 제공 범위를 고지하고, 검증된 가변형 상품 구조를 정할지**를 우선 검토할 필요가 있다. 제품 가격/판매 약속/실제 출력은 사용자 승인 없이 변경하지 않는다.
