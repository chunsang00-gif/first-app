**작업45 정정(2026-11-20):** 아래 $0.104150·6회 호출은 고객 질문이 없는 **유료 첫 장 부적격 합성 사례**를 기준으로 한 금액입니다. 실제 선결제 기술 조건을 충족하는 합성 고객 질문을 넣으면 **8개 장·7회 호출·Luna 전체 $0.125658 예시 원가**였습니다. 두 금액 모두 실제 청구·판매 승인 수치는 아닙니다. [작업45 실측 요청 기반 비용 정정](adaptive-v1-buyer-qualified-luna-cost-correction-20261120.md)을 우선 참고하세요.



## 1. 돈을 실제로 쓸 가치가 있는 원고인가?

이미 비용을 지불한 **Terra 실제 유료 첫 장** 원고를 [기존 비공개 실제 응답 대 무료 비교 결과](terra-real-first-chapter-20261119-verified-value-gap.md)와 대조한 결론을 유지한다.

| 원고 | 검증 결과 | 출처 | 판단 |
| --- | --- | --- | --- |
| 이미 호출한 진짜 유료 첫 장 | 285자, 본문 1문단 | 무료에서 공개한 출생월 근거 2개만 사용 | **유료 가치 부족 / 판매 금지** |
| 이후 작성한 3개 질문 분야의 공개 오프라인 원고 | 출생시간의 별도 분류를 사용한 편집 가설 | 검증한 합성 계산자료 | **실제 유료 모델이 이 원고를 생성한 적 없음** |
| 출생일 추가 원고 2개 | 사용자 질문과 별도 분류를 연결했지만 일반적인 재무·업무 조언 | 출생월과 정확히 중복되는 일지 속글자가 존재 | **우선순위 및 독립 상품 가치 미검증 / 유료 확대 경로 중단** |

**원고 품질의 합격을 증명하는 신규 결과: 0건.** 계산값, 단어가 다르거나 문단이 길다고 유료 가치가 자동으로 생기는 것은 아니다. 기술적으로 생성 가능한 35/96건을 곧바로 구매 가능 고객으로 보고하면 안 된다.

## 2. 실제 추가 장애물 — GPT-4.1 2027년 1월 종료

[OpenAI 공식 API 종료 공지](https://developers.openai.com/api/docs/deprecations)는 GPT-4.1 계열의 2027-01-14 종료 및 GPT-6 Luna 교체를 명시한다. 지금까지 모델 호출 비용 계획의 기준 모델이 GPT-4.1이므로, **출시 전 엔진 교체 검증이 필수**이다.

[OpenAI GPT-6 Luna 모델 안내](https://developers.openai.com/api/docs/models/gpt-6-luna) 기준 일반 텍스트 Standard 요금은 **입력 $0.10, 출력 $0.50 / 100만 토큰**이다. 이 내용은 실제 외부 API 사용량이 아니라 **2026-11-20 공식 공개 표기 가격**이다.

검증 실행 [Actions #44726466868](https://github.com/chunsang00-gif/first-app/actions/runs/44726466868)에서 **실제 서버의 유료 첫 장 작성 요청을 모델 호출 직전에 가로챈 다음**, GPT-6 Luna 요청으로 직렬화하고 서버에서 네트워크 대신 메모리 가짜 응답으로 확인했다.

| 같은 합성 명식·같은 선택 장·같은 출력 토큰 한도 | 기존 GPT-4.1 | 교체 후보 GPT-6 Luna |
| --- | ---: | ---: |
| 계획 시나리오 전체 6회 호출 | 동일 | 동일 |
| **전체 원고 비용 예시(출력 최대치 가정)** | **$1.926680** | **$0.104150** |
| 입력 토큰 정식 실측 | 없음 | 없음 |
| 유료 모델 실제 응답 / 한국어 원고 품질 | 기존 실패 기록만 있음 | **새 응답 없음 / 아직 확인 불가** |
| 실제 교체 모델 API 사용 | 없음 | **없음** |

표의 비용은 **시뮬레이션**이다. 입력은 실제 토큰 수 대신 전송 UTF-8 바이트와 미작성 분량에 대한 보수적 예약 값을 사용했고, 출력은 각 단계 최대 예산을 전부 쓴다고 가정했다. 보장된 비용 상한, 실제 결제 금액, 실제 원고 품질이 아니다. **94.6%**는 그 특정 시나리오의 가격 차이이며 모델 품질 향상률이 아니다.

코드에서는 `report-provider-model-options.js`, `report-paid-batch-plan.js`에 **Luna 요청 형식과 첫 장 출력 한도**를 준비했다. `report-adaptive-v1-offline-cost-plan.js`는 기존 GPT-4.1 기본 동작은 그대로 두고, `inspect({model:'gpt-6-luna'})`로만 대조한다. 서버의 운영 `REPORT_MODEL` 값을 자동으로 바꾸지 않았다.

## 3. 결론과 단 한 번의 다음 필수 검증

지금 제품이 실패하는 이유는 **비싼 모델 가격이 아니라, 실제 생성된 한국어 첫 장이 무료보다 더 낫지 않았던 점**이다. 저렴한 모델 교체만으로 한국어 해석 품질을 해결했다고 말할 수 없다.

다음 개발은 미승인 고전/출생일 근거를 추가하는 실험을 **더 이상 반복하지 않는다**. 이미 구현한 출생시간 근거와 고객 질문을 가진 합성 사례 한 건에 대해, 실제 교체 후보 모델이 무료에서 제공하지 않는 내용을 **독립적인 한 편의 원고**로 출력하는지 확인해야 한다. 새 모델 유료 호출은 사용자의 명시적 동의가 있을 때만 별도로 한다. 그 전에 기술적으로는 비용·실제 요청 본문·질문 범위를 확정한 상태다.

**현재 상품 상태: 작성 후보 구조만 준비 / 유료 원고 검증 실패 / 판매·배포 금지**. 제품 방향(가변형 유료 보고서)은 유지한다.
