# 작업48 — GPT-6 Luna 유료 첫 장 1회 결과의 비공개 사후 검수

검토일: 2026-11-21 (KST)  
개발 브랜치: `fix-paid-qa-fact-bindings-20261014`  
상태: **실제 Luna 모델 호출 0회 / 실제 원고 0건 / 소비자 유료 판매 보류 / 운영 배포 없음**.

## 이번에 실제로 구현한 기능

`qa-luna-private-first-chapter-review.js`: 이전 Terra에 고정된 사람 검토 화면을 새 모델의 1회 결과에도 적용한다. **실제 서버 작성 계약에서 이미 검증한 고정 합성 출생정보/고객 질문**과 GPT-6 Luna 첫 장 본문만 비교한다.

1. **원본 결속**: 모델이 `gpt-6-luna`, 응답 범위가 `saju_core` 단 한 장, 출력 한도가 18,000토큰, `store:false`, 요청 해시가 정확히 `43d7e6bb85ceb415ee8a233a034cd8eb4bd0bf7f6fe5ddc971a6002ae27275f9`인지 확인한다. 1회 시도 기록과 모델 결과 보관 기록이 있어야 한다. **이 메타데이터는 선언된 파일 증거이며 플랫폼 로그의 독립적 인증 자체를 뜻하지 않는다.**
2. **원고 대 무료 검토**: 같은 출생정보의 실제 무료 계산 카드와 저장된 AI 첫 장을 병렬로 보여준다. 두 문단을 혼동하지 않고, 출생시간 겉/속글자 근거 2개 및 고객이 입력한 두 선택의 별도 설명을 검사한다.
3. **기존 모델 검수 실패**: 생성 원고가 읽을 수 있어도 기존 자동 검수에서 탈락했다면 **탈락 상태를 유지**하면서 사람에게 동일 원문을 보여준다. 검사 통과를 꾸며내지 않는다.
4. **불완전 응답**: `incomplete`, `invalid_json`, `empty_output`은 **다시 API를 호출하지 않는다**. 1회 시도를 소비한 실패로 기록하고, 원문/진단 자료의 비공개 보관을 요구한다. 불완전한 내용을 유료 원고로 승인하지 않는다.
5. **보안 및 사람 검수**: 출력 HTML은 로컬 비공개 파일에 권한 `0600`으로 생성하고, 원고 속 HTML은 이스케이프한다. 소스 코드/CI 로그에는 새 고객 원고를 남기지 않는다. 기존 암호화 아카이브(`report-qa-secure-archive.js`)에서 **복호화된 비공개 디렉터리**의 기존 네 가지 이름을 읽는다. 사용자 평가는 파일로만 기록하고 판매 상태를 바꾸지 않는다.

## 실제 사용 시점

이번 코드는 유료 호출 권한을 갖지 않는 **사후 검토 도구**다. 사용자가 **GPT-6 Luna 단 한 번의 유료 호출을 새로 명시 승인**하면 그때만 별도로 신규 GitHub 워크플로우를 설계·고정할 수 있다. 새 워크플로우에서 다음 4개 비공개 JSON을 기록하고, 사용된 원본을 기존 AES-GCM 보관기로 암호화해 비공개 아티팩트에 남기는 단계가 추가로 필요하다.

- `private-qa-first-chapter-attempt.json`: 호출 전 1회 시도 기록
- `private-qa-first-chapter-provider-calls.json`: 실제 응답 및 요청 해시(원문 비공개)
- `private-qa-first-chapter-validated-first-chapter.json`: **자동 검수 통과한 경우에만** 원고와 확인 기록
- `private-qa-first-chapter.json`: 성공 또는 실패 종결 상태

기존 `report-qa-secure-archive.js`에서 내려받은 암호화 자료를 별도 비공개 디렉터리에 복호화한 후, 오프라인에서 실행한다.

```bash
node qa-luna-private-first-chapter-review.js /absolute/private-decrypted-dir /absolute/private-review.html
```

**이 명령은 나중에 실제 원본 자료가 있을 때 쓰는 오프라인 사후 검토 명령이다.** 지금은 입력 원본이 존재하지 않는다. 위 명령으로 AI 원고를 생성하거나 유료 결제를 승인할 수 없다.

## 검증 범위

`qa-luna-private-first-chapter-review-tests.js`에서는 **실제 모델 결과를 쓰지 않은 14가지 합성 오류/정상 사례**를 검증한다. 출처 누락, 일반 조언 반복, 두 선택 설명 누락, 모델 변경, 2회 호출 기록, 다른 장 혼입, 생성 실패, 원본/검증본 불일치, HTML 삽입, 로컬 파일 권한까지 검사한다.

- 자동 검증 통과 = 파일 결속과 **기초 기계적 검수**가 동작한다는 뜻이다.
- 자동 검증은 사주 해석의 전문적 정확성·고객이 지불할 가치를 인증하지 않는다.
- 실제 새 AI 생성 원고의 무료 대비 차별성은 **아직 한 건도 판정하지 않았다**.
- 다음에 실행할 유료 검증은 사용자 **새 비용 동의가 없으면 실행 불가**. 이전 Terra 승인은 소진되었고 재사용할 수 없다.

**결론: 새로운 유료 AI 호출 없이, 그 1회 결과가 실제로 나왔을 때 재결제 없이 합격·불합격을 판정할 비공개 사후 절차를 마련했다. 신규 유료 생성, 자동 재시도, 결제, 운영 배포는 여전히 꺼져 있다.**
