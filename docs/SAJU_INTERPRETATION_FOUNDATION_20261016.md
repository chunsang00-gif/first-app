# 사주×MBTI 유료 보고서: 전통 명리 해석의 근본 기준 (2026-10-16)

> 상태: 문헌 조사에 근거한 **판단 순서·출처·금지 비약**의 작업 기준 초안. 외부 전문가 감수 또는 실제 보고서 품질 합격을 의미하지 않는다.
> 범위: 기존 유료 앱 첫 장의 원리부터 재설계하기 위한 자료. 기존 사주 계산 로직을 임의로 덮어쓰지 않는다.

## 1. 출처 수준의 분리

1. **천문·역법의 재현 가능한 정보:** 한국천문연구원 음양력 변환·역서. 음력/양력·윤달·절입·달력 계산의 교차 검증용이다. 천문기관은 성격이나 미래를 입증하지 않는다.
2. **전통 이론의 원문:** 《연해자평(淵海子平)》 「논일위주·논월령」, 《자평진전(子平真詮)》 「논용신·논십간득시불왕실시불약·논형충회합해법」. 이들은 전통 이론을 이해하는 근거이지 삶의 결과를 실증한 자료가 아니다. 해설자의 현대적 주장과 원문을 분리한다.
3. **한국어 개념·역사 확인:** 한국학중앙연구원 한국민족문화대백과 「사주」「명리정종」.
4. **격국·조후 등 관법의 차이:** 현대 연구 및 관련 원문을 대조하며 학파별 선택을 명시한다. 격국의 '용신'과 억부·조후의 '용신'을 자동으로 같은 개념으로 취급하지 않는다.
5. **상업 블로그·계산기:** 예시와 반례 탐색에만 보조 사용하며 단독 권위 근거로 쓰지 않는다.

## 2. 계산값 / 전통적 판단 / 관찰 사실의 세 단계

- **F(계산값):** 실제 원국 글자, 절입 및 음양력 변환 기준, 일간, 월지, 각 십성, 본기·중기·여기, 실제 합충 위치, 근거 출처 ID. 재현 가능한 입력·알고리즘으로 검증.
- **T(전통적 해석):** 어떤 명리 관법에서 F를 어떤 상징적 질문으로 읽는지. 서로 다른 요소가 어떻게 함께 작용하는지 검토하여 조건부로 풀이. 이론의 이름과 전제가 내부에 기록되어야 함.
- **O(사실 주장):** 실제 인물의 성격·능력·생애·재산·건강·미래 결과. 출생 자료만으로 O를 입증하지 않음. F → O 직행 금지. T → O 확정 서술 금지.

전통 해석은 경험과학적으로 검증된 성격 검사나 미래 예측을 의미하지 않는다. 허용되지 않은 확정 판단을 '조금 완곡한 말투'로 바꾸는 것은 오류 해결이 아니다.

## 3. 읽는 순서 (의도적 판단 순서, '좋다/나쁘다' 자동 공식 아님)

1. **역법 선확정:** 음력/양력·윤달, 입춘 연주 경계, 12절의 월주 경계, 출생시각, 표준시·경도/진태양시 미보정 여부, 자시 분기 규칙, 출생시 미상 범위. 경계값은 외부 신뢰 자료와 비교하고 불확실하면 보류.
2. **일간과 네 기둥:** 일간의 음양·오행을 해석의 기준으로 둔다. 연·월·일·시 각각의 위치와 그 글자들이 실제로 무엇인지 확인. 위치 하나가 곧 성격이라는 공식은 만들지 않는다.
3. **태어난 달과 계절:** 월지가 어느 계절인지, 전환 구간인지, 중심 숨은 글자와 절입상 조건은 무엇인지 본다. **계절이 전환기 = 변화에 능하다/성격이 유연하다** 같은 비약 금지. 월지 본기 하나로 사령·격국·용신 확정 금지.
4. **십성 분류:** 일간 기준 다섯 관계(비겁=나와 같은 쪽, 식상=내가 생하는 쪽, 재성=내가 제어하는 쪽, 관성=나를 제어하는 쪽, 인성=나를 생하는 쪽)와 음양 구분에 따른 10개 항목을 계산한다. 실제로 있는 **천간의 십성**과 지지 안에 숨은 십성을 구분한다. 분류의 명칭이 곧 그 사람의 행동이나 돈벌이 능력은 아니다.
5. **출처 간 관계:** 월지·십성·노출 여부·배치·기운의 생극 관계를 함께 읽어 한 방향을 뒷받침하거나 제약하는 근거를 비교한다. 같은 글자가 두 번 보인다고 강도가 두 배가 되지는 않는다. 근거가 한 가지면 개인별 강점·단점의 확정 설명으로 확장하지 않는다.
6. **통근·합충은 필요할 때 보조 검토:** 숨은 동일 기운의 실제 위치와 강도 미산정은 구분한다. 충은 **그 두 끝점**을 계산하고, 겹친 충이 뿌리를 없애거나 반드시 현실의 갈등/불안이라는 주장은 하지 않는다. 해당 문단에서 해석상 왜 중요한지 설명할 수 없으면 고객용 본문에 쓰지 않는다.
7. **방법론 선택의 가시성:** 자평 계열의 월령·격국 중심 판단, 조후(계절 기후) 중심 접근, 부억 중심 접근은 질문과 개념이 다를 수 있다. 규칙이 완성·검증되지 않은 방법으로 자동 격국·용신·신강약 등을 판정하지 않는다. 상충하면 내부에서 '미판정'하고 다른 체계를 섞어서 정답인 것처럼 제시하지 않는다.
8. **분야에 맞는 제한적 연결:** 기질·관계·일·돈·특정 연도는 **그 질문을 지지하는 별도 관련 근거**가 있을 때만 다룬다. 원국 합충 하나로 금전 손실, 2027년 취업·결혼·이별, 실제 건강을 예언하지 않는다.
9. **MBTI 독립 비교:** 입력된 MBTI 선호와 사주 상징을 독립적으로 풀이하고 공통점/차이가 실제로 성립할 때만 비교한다. 사주가 MBTI의 진위를 증명하거나 정반대 결론을 반드시 내야 하는 것으로 다루지 않는다.
10. **문장 순서:** 고객의 질문 → 실제 확인된 근거의 전통적 의미 → 다른 근거와의 조건부 비교 → 가정형 적용 상황 → 꼭 필요한 한계 1회. 기술 용어·경로 ID·계산 근거 목록은 내부 basis/evidence에 보존. **설명할 수 없는 것은 자신감 있는 성격 묘사로 대체하지 않는다.**

## 4. 십성을 고객에게 풀이할 때의 출발점

| 명리 관계 | 전통적으로 살펴보는 주제(예시) | 금지되는 직접 결론 |
| --- | --- | --- |
| 인성(정인·편인) | 배움·수용·보호·도움 | 실제 공부를 잘함, 빨리 배움, 보호받은 인생 |
| 식상(식신·상관) | 표현·산출·전개 | 말 잘함, 창의성이나 생산성 확정 |
| 재성(정재·편재) | 대가·재물·자원의 처리 | 부자, 돈 관리 우수, 투자 성공 |
| 관성(정관·편관) | 역할·규칙·압박의 관계 | 반드시 책임감 강함, 승진·권력 |
| 비겁(비견·겁재) | 같은 편·협동·경쟁의 관계 | 고집이 셈, 독립적, 실제 경쟁 경험 |

한 가지 십성을 발견했다고 그 성격을 결론 내지 않는다. 음양의 세부 구분, 노출/숨은 위치, 계절·다른 글자와의 관계, 선택한 관법이 중요하다. '없는 글자'를 부정적 특성으로 자동 전환하지 않는다.

## 5. 2·3차 유료 원문에서 반복된 오류 유형

- 뿌리 두 곳과 각각의 충을 **서로 충돌하는 두 성격의 중심**처럼 풀이함.
- '전환월'을 곧 '변화 적응 능력'으로 바꿈.
- '물의 인성'을 실제 학습·감정·지원 경험으로 바꿈.
- 계산·용어를 반복하거나, 용어만 지운 뒤 '두 중심의 균형'이라는 비검증 성격을 발명함.
- 긴 면책 문구를 해석의 깊이처럼 취급함.

이 오류들은 어투의 문제가 아니라 **추론 사슬 F→T의 부재, 또는 T→O의 무근거 비약**에 해당한다. 지엽적인 금지어를 추가하는 것만으로 근본 개선이 되지 않는다.

## 6. 사전 수락 조건 (실제 코드 수정에 적용할 설계 계약)

- 모든 고객용 핵심 판단은 내부에 근거 출처 **2개 이상이 필요한지를 먼저 판단**한다. 단일 근거로도 정당한 제한적 분류 설명은 가능하지만, 상호작용·개인 장단점을 확정하지 않는다. 근거의 개수만 늘리는 것도 충분한 논리가 아니다.
- '어떤 사실이 왜 어떤 전통 해석의 조건인가'가 **사례·관법과 함께 명시**되어야 한다. 이를 설명할 수 없으면 제한된 해석으로 축소한다.
- 매 문단에 결론을 강제로 만들지 않는다. 근거가 부족하면 해당 선택 항목은 비우고, 필수 내용도 범위 내에서 풀이한다.
- 서로 다른 출생명식, 출생시각 미상, 절입 경계, 같은 계절 다른 십성, 같은 십성 다른 계절, 충의 유무를 회귀 검사한다.
- 생성된 글에서 '고객에게 새로운 해석적 통찰이 있는가'는 **자동 테스트만으로 합격 선언하지 않고 실제 사람의 독해·전문가 검토를 요구**한다.
- **유료 API 실행 승인 없이 비용을 쓰지 않는다.** 1회 실제 유료 생성에도 실패 시 원문 보관·추가 호출 금지·수동 품질 판단을 유지한다.
