# 1982년 양 시각: 고전의 일반 원칙 후보와 특정 예시의 구분 (2026-10-24)

## 수정된 판정

《자평진전》 「十、論用神變化」 [원문 전사](https://caipu.donglishuzhai.net/chapter/3723.html)는 태어난 달에 숨은 여러 글자의 겉 노출에 따른 해석 출발점 변화를 **일반 원칙**으로 설명한 다음, 寅월·辛일과 甲·丙의 겉노출에 관한 **구체적 사례**를 설명한다. 모든 사주에 그 구체적 사례의 결론을 적용할 수는 없다.

기존 앱에서는 구체적 사례가 불일치하는 1982년 샘플에 \`no-applicable-textual-precedent\` 상태만 주어, 일반 원칙을 검토할 **구조적 후보**까지 놓치기 쉬웠다. 이번에는 다음을 분리했다.

| 조건 | 오후 2시 20분 | 오후 8시 20분 |
| --- | --- | --- |
| 출생 사주 | 壬戌/癸丑/乙未/癸未 | 壬戌/癸丑/乙未/丙戌 |
| 달의 숨은 글자 | 己·癸·辛 | 동일 |
| 기본 글자 己의 해·달·시간 노출 | 없음 | 없음 |
| 다른 숨은 글자 癸의 노출 | 달·시간 | 달 |
| 다른 숨은 글자 辛의 노출 | 없음 | 없음 |
| 원문 일반 원칙의 구조 검토 | 후보 | 후보 |
| 寅월 辛일의 구체적 원문 예시 | 해당 없음 | 해당 없음 |
| 편인 또는 다른 격국의 최종 우선순위 | **미판정** | **미판정** |

## 정확히 허용되는 내용

두 사례에서 월의 기본 글자는 겉에 나오지 않고 다른 숨은 글자가 겉에 나온다. 따라서 월의 숨은 글자 노출을 따져 보는 이 고전의 **일반 질문**이 관련된다. 노출을 재검산하면 14:20에는 달과 시간 두 자리가, 20:20에는 달 한 자리가 후보 글자와 정확히 일치한다.

다만 이 구조만으로 편인격이나 길흉을 확정해서는 안 된다. 고전의 특정 寅월 辛일 사례의 **정관/정재 우선 결론**을 이 乙일 丑월에 복사할 수도 없다. 달과 날의 관계, 삼형의 후대 주석, 실제 사령과 다른 글자의 상호 작용 등을 전문가가 검토하기 전에는 전통적 우선순위가 미정이다.

## 변경 코드

- \`report-core-paid-classical-decision-handoff.js\`: 전문가가 결정해야 할 달의 우선순위 질문에 구조적 근거를 전달한다.
- \`report-core-paid-adult-two-hour-contrast.js\`: 시간 변경 전후의 월 후보 자체는 같고 **노출 자리만 달라지는 점**을 검증한다.
