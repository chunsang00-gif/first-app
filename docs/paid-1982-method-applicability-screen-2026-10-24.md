# 1982 사주 전통 해석 방법 선별 — 2026-10-24

QA용 명식: 음력 1982-11-24, 14:20 대 20:20, 2027년 대상.

## 실제 적용 후보

- 두 시간 모두 丑월 본기 己는 연월시 겉에 나오지 않는다. 다른 숨은 글자 癸는 14:20에 월·시, 20:20에는 월에서 정확하게 확인된다.
- 따라서 《자평진전》 「論用神變化」의 숨은 월 글자 노출에 관한 일반 원칙은 검토 후보이다. [원문 전사](https://caipu.donglishuzhai.net/chapter/3723.html)

## 적용 제외

- 원문에 명시된 辛일 寅월의 甲·丙 노출 사례는 乙일 丑월 사주와 불일치하므로 그 사례의 정관·정재 우선 결론은 적용하지 않는다.
- 两 명식 모두 월 丑을 포함해 세 위치에 완성된 삼합·방합이 없으므로, 완성된 세 글자 모임으로 월의 성질이 달라졌다는 결론은 적용하지 않는다.
- 丑·戌·未의 전통 형 범주와 실제 지지 관계표는 삼합·방합의 완성이나 작용 강도를 대신하지 않는다.

## 여전히 검증되지 않은 것

- 어느 숨은 글자가 실제 사령을 맡는지, 월의 어떤 분류를 우선할지, 월과 다른 출생 자리 관계가 해석에 어떻게 영향을 줄지.
- 개인 성향, 직업 적합성, 재물, 2027년 사건은 위 출생 계산만으로 관찰된 사실이 아니다.

결과는 report-core-paid-classical-decision-handoff.js의 methodApplicabilityDecision으로 제공된다. QA 범위를 벗어나 정상 유료 생성기에 전달하지 않는다.


## 해·달·시간의 겉글자 상호관계 검증 (추가)

이름이 비슷하다는 이유로 여러 해석 후보를 한꺼번에 우선시키지 않도록, 기존 오행 방향 계산기(`report-core-paid-natal-mixed-visible-reconciliation.js`)의 결과를 원본 근거 ID와 함께 재사용한다.

| 검토 | 14:20 | 20:20 |
| --- | --- | --- |
| 겉글자 (해 / 달 / 시간) | 壬 / 癸 / 癸 | 壬 / 癸 / 丙 |
| 같은 오행으로 분류된 자리 쌍 | 3쌍 (물·물) | 1쌍 (해·달 물) |
| 물이 불을 제약하는 방향 관계 | 없음 | 2쌍 (해·시간, 달·시간) |
| 해의 壬와 달의 癸 | 같은 오행, **서로 다른 글자·십성(정인/편인)** | 동일 |
| 실제 강약 / 작용의 우선순위 | 미판정 | 미판정 |

**주의:** 해의 壬가 달의 숨은 글자 癸와 같은 물이라는 이유로 `癸`의 정확한 겉노출이라고 주장할 수 없다. 20:20에 물이 불을 제어하는 두 화살표가 계산되더라도 실제로 시간의 분류가 약해지거나 인생에서 더 불리해진다는 결론은 나오지 않는다. 마찬가지로 14:20에 모두 물로 계산된다고 해당 성향의 힘이 3배가 되는 것은 아니다. 이 출생시간 차이는 **전통적 해석에서 추가 검토해야 할 조건**이지 개인의 행적·미래에 대한 증명이 아니다.

이 결과를 `report-core-paid-classical-decision-handoff.js`의 `methodApplicabilityDecision.unresolved.otherPillarVisibleInteractions`에 보존하고, 14:20/20:20 반례 테스트에서 숫자·방향·상징 분류를 검증한다. 자동 우선순위 선택, 정상 유료 요청 연결, 프로덕션 배포는 하지 않았다.
