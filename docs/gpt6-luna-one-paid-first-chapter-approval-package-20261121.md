## 실제 원고가 도착하면 합격과 실패를 어떻게 판정할 것인가

합성 명식의 **현재 무료 풀이 본문과 새로 생성된 유료 첫 장을 나란히 놓고**, 사람이 아래 다섯 가지를 판정한다.

1. 유료 문단이 **이미 무료에 나온 출생월 설명을 재포장**하지 않는가?
2. 계산된 출생시간 추가 분류(식신)가 고객의 두 선택 **각각에 다른 질문/조건**을 제공하는가?
3. 고객이 말하지 않은 실적·직업 경력·능력·성격·미래 사건이 지어지지 않았는가?
4. 십성 사전풀이·어려운 용어·반복·일반 취업 조언으로 분량을 채우지 않았는가?
5. 무료를 먼저 읽었을 때도 **독자가 이 첫 장에 돈을 낼 실제 이유가 있는가?**

하나라도 불충족이면 **품질 불합격/판매 보류**. 자동 테스트만 통과하거나 원고 길이가 늘었다는 사실로 합격 처리하지 않는다. 새 모델의 실제 호출/출력, 한국어 품질, 명리 해석의 전문성, 고객 지불 의사는 모두 **미검증**.
