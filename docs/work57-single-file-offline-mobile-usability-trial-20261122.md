# 작업57 — 서버·결제 없이 실제 앱 계산 코드를 체험하는 HTML 1개

작성일: 2026-11-22 (KST). 개발 브랜치: `fix-paid-qa-fact-bindings-20261014`. **운영 배포 / 유료 AI 호출 / 상업적 판매 / 실고객 설문 수집 없음**.

## 목적

작업52~56에서는 사주×MBTI 앱의 첫 단계 안에 **고객 직접 입력 시간·예산 계산 미리보기**를 추가했지만, 이를 실제 손으로 열어보지 않고 GitHub의 정적 테스트만 반복했다. 사용자 관점의 화면 가독성·입력 피로도·실제 체험은 검증되지 않았다.

이번 작업은 별도 배포 승인 없이 체험할 수 있는 **단일 오프라인 HTML** `workbook-mobile-offline-trial.html`을 개발 브랜치에 추가한다. `report-buyer-work-skill-scope.js`, `report-buyer-decision-context.js`, `report-work-skill-decision-workbook.js`, `report-work-skill-decision-comparison.js`, `report-work-skill-decision-workbook-ui.js` **현재 다섯 모듈과 기존 CSS를 원문 그대로 포함**한다. 해석/계산 로직을 새로 복제하지 않는다.

## 실제 체험 순서

1. GitHub의 `saju-mbti-tests` 성공 실행 페이지 **Artifacts**에서 `work57-single-file-offline-mobile-trial` ZIP을 내려받는다. ZIP을 풀어 `workbook-mobile-offline-trial.html` 파일을 로컬 브라우저로 연다. GitHub 접근 권한과 해당 기기·브라우저의 로컬 HTML 실행 지원 여부에 따라 여는 방법이 달라질 수 있다. **파일을 웹에 배포한 URL은 없다**.
2. 숫자 2개만 입력한다. 예: `주당 학습시간 8`, `목표 8주`. **64시간 배치 가능**이 보여야 한다. 총 필요 학습시간·업무명·기술명·교육비를 입력할 필요는 없다.
3. **합성 예시 자동 입력**을 눌러 현재 일 `물류 재고 확인`, 새 기술 `엑셀 자동화`, 주 3시간, 필요 60시간, 8주, 교육비 30만원/가용 예산 10만원을 채운다. 계산상 `36시간 부족`, `교육비 20만원 부족`, `주당 4.5시간 추가` 또는 `목표 12주 연장`이 보여야 한다. 실제 삶·소득·취업을 예측하는 뜻은 아니다.
4. **전체 입력 초기화**를 누르면 숫자·선택 입력과 체험 의견이 비워져야 한다. 사용자는 자기 생년월일, 회사명, 연락처를 넣지 않는다.
5. 화면 아래 **결과 이해 정도**, **가장 어려운 단계**를 선택한 다음 **피드백 문구 만들기** 버튼을 누른다. 문구는 자기 손으로 복사해 대화로 전달한다. 자동 발송·저장·수집 기능은 없다. 자동으로 복사한 문구에 개인 업무명이나 숫자가 섞이지 않도록 제한했다.

## 검증 경계

- [`qa-workbook-mobile-offline-trial-tests.js`](../qa-workbook-mobile-offline-trial-tests.js)는 **체험 HTML에 포함된 실제 5개 JS 원문이 현재 원본과 문자 단위로 일치하는지** 확인한다. 원본이 바뀌고 오프라인 파일만 오래된 경우 빌드를 실패 처리한다.
- 실제 HTML에 포함된 프로그램을 **가상 DOM에서 실행**하여 숫자 2개로 사전 계산 → 예시 자동 입력 → 부족 시간·금액 → 의견 생성 → 초기화 흐름을 검사한다.
- `Content-Security-Policy`에서 기본 네트워크·연결·이미지·제출·외부 객체를 금지한다. 외부 JS/CSS 링크를 넣지 않는다. 원본 앱의 서버 계산·제출을 이 파일에 복사하지 않으며 브라우저 `fetch`, `XMLHttpRequest`, `localStorage` 요청을 사용하지 않는다. 테스트에도 외부 요청을 차단한다.
- 메인 앱의 `public-files.js`에는 이 파일을 추가하지 않는다. 본 개발 브랜치 원본과 GitHub Actions 파일로 다운로드하도록 하며, 운영 앱에서 별도 페이지가 열리지는 않는다.
- **가상 DOM 자동 검증이 실제 휴대폰의 시각/터치/보조기기 테스트를 대신하지 않는다.** 실제 이용자가 실행한 횟수, 만족도, 지불 의사는 아직 수집되지 않았다. 체험판을 무료 보고서 품질의 검증이나 사주×MBTI 유료 상품 출시 승인으로 취급하지 않는다.
