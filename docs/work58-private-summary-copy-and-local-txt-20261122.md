# 작업58 — 결과를 가져갈 수 있는 실제 계산 요약·복사·텍스트 저장

작성: 2026-11-22 (KST)  
브랜치: `fix-paid-qa-fact-bindings-20261014`  
상태: 개발 브랜치 / 로컬 무료 기능 / 운영 배포 없음 / 유료 AI·결제·판매 승인 없음.

## 달라진 점

작업57에서 **실제로 실행하는 체험판 HTML**과 수동 피드백 양식은 준비됐지만, 고객이 학습시간·비용 계산 결과를 나중에 참고하려면 **화면을 캡처하거나 숫자를 다시 적어야 했다**. 이 문제를 실제 앱과 오프라인 체험판에서 동시에 해결했다.

실제 앱 첫 입력 단계(학습시간·예산 비교)에 **「결과 가져가기」**를 추가했다.

1. 학습시간 2개(예: 주당 8시간, 목표 8주), 또는 필요 총시간+목표 기간, 또는 교육비+가용 예산처럼 **2개 값만으로 계산 가능한 상황**에서만 버튼이 나타난다. 입력이 아예 없거나 숫자가 잘못됐다면 저장 버튼을 보여주지 않는다.
2. **「복사용 요약 만들기」** 버튼을 눌러 **직접 입력한 수치와 그에 근거한 계산 결과**를 텍스트로 먼저 확인한다. 빈 입력은 **미입력**이라 표기한다. 학습 필요시간이 없으면 부족시간을 0이라고 적지 않는다.
3. 이후에만 **「텍스트 복사」** 및 **「텍스트 파일 저장」** 버튼을 활성화한다. 기기에서 클립보드 권한을 거절했거나 `file://`에서 사용 불가한 경우 자동 전송하지 않고 **사용자가 텍스트를 선택해서 복사**할 수 있게 한다.
4. 저장은 사용자가 버튼을 누르면 **기기의 `.txt` 다운로드**를 요청한다. 일부 브라우저·파일 앱에서는 저장이 차단될 수 있으므로 원문을 직접 복사하는 대체 방법이 있다. 생성 파일명은 `learning-time-budget-summary.txt`다.
5. 값을 하나라도 수정하거나, 질문을 다른 주제로 바꾸면 **앞서 만든 요약을 즉시 지우고 복사/저장 버튼을 비활성화**한다. 요약을 다시 만들어야 새 값을 가져갈 수 있다.

## 사용자의 내용을 어떻게 보호하나

새 파일 `report-work-skill-decision-private-export.js`는 실시간 계산 원본 `report-work-skill-decision-workbook.js`의 **같은 산술 함수를 다시 실행**해 화면 숫자를 대조하고, **고정된 익명 업무명**으로 필요한 조정 방법을 다시 계산한다.

- **제외:** 자유입력 고민 문장, 회사명·현재 업무명·배울 기술명, 생년월일, MBTI, 전화번호 및 기타 텍스트
- **포함:** 주당 학습 가능시간, 필요 학습시간, 목표 기간, 예상 교육비, 가용 예산, 이 수치에서 직접 계산한 부족 조건·확인 사항
- **주의:** 숫자도 개인적 정보일 수 있으므로 다른 사람에게 전달할 때는 사용자가 직접 내용을 읽어본 뒤 선택해야 한다.
- 화면은 데이터를 외부 AI로 보내거나 결제하는 새 호출을 만들지 않는다. **저장·복사 버튼을 누르지 않으면 파일 생성이나 클립보드 변경은 없다.** 저장된 텍스트 파일은 사용자 기기에 남을 수 있으며 사용자가 직접 관리해야 한다.

## 실제 수정 경로

- `report-work-skill-decision-private-export.js` — 숫자만으로 유효성 재확인, 누락 처리, 조정안 문구를 고정 익명 입력으로 재계산
- `report-work-skill-decision-private-export-ui.js` — 실시간 데이터 변경 감지, 생성·복사·TXT 저장·권한 부족 시 직접 선택
- `index.html` 및 `report-work-skill-decision-workbook.css` — 기존 첫 입력 화면에서 결과 아래 복사·파일 저장 UI 표시
- `public-files.js` — 두 새 JS만 허용. 체험판 HTML과 자동 테스트는 공개 운영 경로로 연결하지 않음
- `workbook-mobile-offline-trial.html` — 같은 새 코드를 원문 그대로 포함시켜 **오프라인 휴대폰 체험판에도 결과 저장/복사 가능**
- `qa-work58-private-export-tests.js` — 부분/완전/영시간/숫자 누락/변조 방지/비노출 경계 테스트
- `qa-workbook-mobile-offline-trial-tests.js` — 실제 임베드 코드를 가상 브라우저로 실행해 예시 입력·요약 생성·수동 복사·Blob 저장·입력 초기화 검증
- `.github/workflows/test.yml` — 위 검증을 필수 CI 단계에 편입하고, 다운로드 가능한 HTML을 계속 Artifacts에 첨부.

## 실제 체험 방법

GitHub Actions 성공 실행의 **Artifacts** 항목에서 `work57-single-file-offline-mobile-trial` 파일을 내려받아 ZIP을 해제한다. `workbook-mobile-offline-trial.html`을 로컬 브라우저에서 열고, **합성 예시 자동 입력 → 결과 가져가기 → 복사용 요약 만들기 → 텍스트 파일 저장** 흐름을 사용한다.

이것은 **실제 유료 첫 장 원고를 판매하는 기능이 아니다.** 기존 유료 보고서 작성기·AI 비용·결제 판단 게이트는 변경하지 않았다. 고객의 실제 사용성·지불 의사는 여전히 검증되지 않았다. Android/iOS 브라우저의 파일 다운로드/클립보드 권한을 실제 기기에서 직접 테스트한 결과도 아직 없다.

**결론:** 고객이 개발 중인 계산 결과를 가져가 검토할 수 있는 기능을 추가했으나 **유료 출시·상품 가치는 미승인**이다.
