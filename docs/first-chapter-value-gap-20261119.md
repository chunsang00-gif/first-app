# 작업18 — 무료 풀이 대비 유료 첫 장의 독자 가치 점검

**날짜:** 2026-11-19  
**검토 대상:** 기존의 검증용 음력 1982-11-24 14:20 / ISFP 합성 사례  
**검증 방식:** 실제 로컬 계산으로 생성되는 무료 본문과 사람이 작성한 공개 유료 첫 장 예시를 같은 출생정보로 비교  
**제외:** 비공개 Terra 실제 원고, 새로운 모델 응답, 실제 결제, 운영 배포

## 직접 비교한 내용

| 항목 | 무료 풀이에서 이미 제공되는 것 | 공개 유료 첫 장 예시의 차이 | 편집 판단 |
|---|---|---|---|
| 출생월 | 달의 겉글자 및 중심 숨은 글자의 전통적 질문 | 출생월 두 분류를 풀어 설명하는 `strength` 문단 | **기존 무료 의미 반복에 가까움. 독립된 유료 가치를 주장하지 않음** |
| 출생시간 | 해와 시간의 **겉글자**에 해당하는 전통적 뜻 | 별도 검증된 출생시간 **안쪽 글자 丁(식신)**의 질문 | 출처가 다르다는 것은 계산으로 확인. 실제 삶에 미치는 효과는 미검증 |
| 현재 업무 유지 | 제공하지 않음 | 사용자가 직접 쓴 '출하 전 품질 검수 및 준비'를 전제로 누락 건수·처리 시간을 같은 기간에 비교 | 고객 입력을 활용한 실무 질문. 사주가 이 업무 경험이나 성과를 증명한 것은 아님 |
| 새 기술 학습 | 제공하지 않음 | 사용자가 직접 쓴 '지게차 실습과 자격 취득'을 전제로 연습 동작 완료·기간·비용을 확인 | 다른 조건을 묻는 실무 질문. 합격·습득 속도 예언이 아님 |

## 지금 유료 원고 예시가 실제로 더하는 것

1. **계산된 추가 근거:** 무료의 출생시간 겉글자 설명과 달리, 시간 안쪽 글자 丁의 '익힌 것을 결과물로 마무리'라는 전통적 질문을 사용한다.
2. **고객이 직접 제공한 선택지 구별:** 기존 검수 업무는 누락 건수·처리 시간의 비교, 배우려는 기술은 실습 완료 조건·기간의 점검으로 분리한다.
3. **주장하면 안 되는 것:** 위 두 가지로 실제 직무 능력, 성격, 학습 속도, 합격, 수입, 더 유리한 직업을 결정했다고 말하면 안 된다.

## 출시 판단

**유료 판매 승인: 보류.** 위 예시는 자동 검증 가능한 근거 연결과 선택지 구별에 대한 실험용 원고일 뿐, 실제 유료 AI가 생산한 텍스트가 아니다. 입력 질문에 답하는 일부 문장은 일반적으로도 유용한 업무·학습 조언이므로, 출생정보 덕분에 새롭게 얻은 개인 해석의 상품성이 입증됐다고 볼 수 없다.

실제 출시 후보 판정에는 **비공개 실제 유료 첫 장 원고**를 기존 `qa-terra-first-chapter-human-review.js` 및 `qa-first-chapter-human-value-review.js`를 통해 같은 무료 풀이 옆에 놓고 읽는 독립 검수가 필요하다. 이미 생성된 원고를 비교할 때 모델 호출을 다시 하지 않는다.

## 이번 코드 작업

- `qa-first-chapter-reader-editorial-prototype.js`: 사용자가 적은 현재 업무와 새 기술을 반영하는 공개 유료 예시 개정
- `qa-first-chapter-reader-editorial-prototype-tests.js`: 같은 출생정보의 무료 내용 불변·자가 입력 근거 분리 확인
- `qa-first-chapter-value-audit.js`: 현재 무료 내용을 실제 계산하고 공개 유료 예시와 나란히 출력하는 개발용 Markdown 생성기
- `qa-first-chapter-value-audit-tests.js`: 무료 본문 정합성과 판매 미승인, 네트워크 호출 없음 검사

**주의:** 이 보고서와 공개 예시는 비공개 Terra의 실제 유료 원고가 아니며, 자동 테스트 성공은 판매 승인으로 연결되지 않는다.
