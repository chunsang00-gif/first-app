## 배경 — 기존 앱은 무료 대비 차이만 확인하고 있었다

기존 유료 첫 장의 `temperament` 추가 문단은 **출생시간 숨은 글자**의 십성이 무료 풀이에서 공개된 출생월·출생년/시간 겉글자의 십성과 다른지를 확인했다. 원국 **다른 기둥에 이미 똑같이 있는 숨은 글자**까지 살펴본 것은 아니었다.

오프라인 원국 96개 사례에서 실제 출생시간 유료 후보가 **35개**, 그중 **26개는 선택된 시간 숨은 글자의 정확히 같은 글자가 출생년·월·일의 다른 위치에도 존재**, 나머지 **9개는 같은 글자가 다른 위치에 없었다.** 이는 96개의 **합성 질문**에서 얻은 통계이며 고객분포·매출 전망이 아니다.

기존 합성 테스트 사례 `壬戌 / 癸丑 / 乙未 / 癸未`에서는 시지의 `丁`(식신)이 이미 **연지 戌 및 일지 未의 안쪽 `丁`**으로 존재한다. 따라서 '무료에 없는 위치'라는 사실만으로 **원국에서 새로운 전통 분류를 발견했다고 말할 수 없다**. 같은 글자라도 자리별로 다른 의미를 연구할 수 있다는 점 자체를 금지하는 것은 아니지만, 현재 제품은 그 차이의 전통적 해석·우선순위를 **전문적으로 검증한 유료 방법을 갖고 있지 않다**.

## 실제 생산 경로의 변경

- `report-paid-core-precharge-value.js`: 원국 전체 반복 검증 `report-paid-core-hour-cross-pillar-audit.inspect(packet)`를 실제 **모델/결제 전 유료 첫 장 사전검사**에서 사용한다. **중복 글자면 `eligible=false`**, 이유는 `hour-role-already-in-other-natal-pillar-unreviewed-positional-meaning`. 기존 독자 질문/선택 입력 오류의 구체적인 거절 이유도 보존한다. 어떤 경우에도 판매 승인이나 모델 호출은 수행하지 않는다.
- `report-paid-core-hour-extension.js`: **실제 유료 작성기가 받는** 출생시간 심화 요청에 원국 다른 위치의 동일한 글자를 명시하고, 반복 글자를 '출생시간에서만 새롭게 발견된 십성'으로 표현하지 않게 작성 지침을 변경했다. 전체 원국의 출처를 일관되게 계산하되 실제 응답의 인용 가능 출처는 기존 출생시간 두 개만 유지한다. **중복 글자 관련 자기확신을 방지하는 지침일 뿐 실제 원고 품질을 증명하지 않는다**.
- `report-product-coverage.js`: 결제 전 고객용 상품 범위 화면에 '원국 다른 위치에도 같은 글자가 있어 유료 첫 장을 제공하지 않는다'는 **구체적 안내**를 추가한다. 유료 모델·결제·운영 배포 연결은 열지 않는다.
- `qa-first-chapter-cross-domain-editorial-pack.js`: 기존 수작업 예시 3개는 **역사적인 편집 검토 자료로 보존**하지만, 새 주문 전 검사에서 차단된 사례를 **판매 가능한 후보로 과장하지 않도록** 편집 자료에 사전검사 상태·중복 위치를 표시한다.
- 기존에 소비됐거나 철회된 **Terra와 Luna QA 승인**은 재사용하지 않는다. 원래 해시와 현재 요청이 다른 것은 안전한 거절 사유이지 승인 갱신이 아니다. 이전 양자택일 원고는 유료 모델 출력이 아닌 사람 작성 예시로 남는다.

## 보수적인 가치 판정

- **확인된 사실**: 서로 다른 기둥에 동일한 글자가 존재하는 원국 계산은 정확히 검사할 수 있다.
- **확인되지 않은 사실**: 새 위치에서 등장한 같은 글자가 실제 개인의 특별한 성향·능력·직업 선택·돈의 결과를 설명한다는 인과 관계 및 전통적 전문 해석의 우선순위.
- **변경된 동작**: 사전검사에서 반복 원국 기호의 자동 유료 자격을 부정. 원국 전체에서 중복되지 않는 심화 후보는 **기술적 후보**로만 남겨둔다. 고객에게 돈 받을 가치가 증명된 것은 아니다.
- **전체 판매 상태**: 실제 유료 원고의 내용이 독립적으로 검증되지 않았고 `report-commercial-readiness.assessAdaptive()`에서 `independentlyReviewedPaidManuscript=false`이므로 **운영의 실제 결제는 계속 막혀 있다**.

이번 변경의 핵심은 **'무료 화면에서만 새로 보이는 글자'와 '원국 전체에서 독립적인 근거'를 구별하는 실제 주문 전 방어선**을 구축한 것이다. 다음 단계는 더 많은 체크리스트를 만드는 게 아니라 원고 품질과 전통적 위치별 해석을 사람에게 검증받는 것이다. **미리보기용 계산 워크북의 기능을 유료 사주 해석이라고 포장하지 않는다.**
